# Introduction

Workflow Docs is a client-friendly, staff-ready way to build smarter legal documents, integrated directly into LegalServer.

## Choose Your Path

Select the guide most relevant to your role:

- [**Advocate Guide**](/docs/advocate-guide): Learn how to generate documents, collect signatures, and use AI follow-ups on your cases.
- [**Template Author Guide**](/docs/template-author-guide): Learn how to build dynamic templates using variables and logic.
- [**Administrator Guide**](/docs/admin-guide): Learn how to configure LegalServer integration and manage workflow filters.

## Key Features

- **Integrated with LegalServer**: Launch interviews and save documents directly to the case file.
- **Multi-Party Signing**: Send one batch of documents to multiple clients, witnesses, or attorneys — each gets a personal link to review, fill in their fields, and sign. See the [Multi-Party Signing guide](/docs/multi-party-signature).
- **Smart Templates**: Use AI to draft templates and logic. Author with Jinja2 — no interview coding required.
- **Electronic or Print**: Generate documents for e-signature, or produce clean printable PDFs/DOCX for paper signatures.
- **AI-Powered**: Generate one-off documents and follow-up questionnaires using the configured AI provider. Workflow Docs typically uses Azure OpenAI Service; administrators may configure OpenAI directly, and template auto-labeling can use Google Gemini. Customer data is not used to train AI models and is encrypted in transit and at rest; handling and retention follow the provider's enterprise terms.
- **Multi-Language**: Each organization can pick which client languages are offered (English, Spanish, Chinese, Portuguese, Haitian Creole, Vietnamese, Khmer).
- **Template Companion Actions**: Stamp compliance flags and create case notes on the LegalServer matter automatically when a document is finalized. See [Template Actions](/docs/template-actions).
- **Community-Resource Enclosures**: Build a shared YAML library of links and QR codes, then let the advocate pick a tailored subset per template. See [Link Enclosures](/docs/link-enclosures).
- **Client Engagement**: Secure e-signatures, document uploads, and SMS or email delivery.
- **Secure & Private**: Data is encrypted at rest and in transit. [Learn more about our security standards](/security).
- **Onboarding Support**: Start off on the right foot with 3 key templates custom automated for you at no extra cost (up to 15 fields per template).
