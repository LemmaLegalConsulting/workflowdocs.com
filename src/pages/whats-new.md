# What's New

Here are the latest Workflow Docs features and improvements.

## Version 1.5.6 — August 27, 2026

### Clearer progress through workflows

Document assembly, document requests, and questionnaires now show clearer
progress sections, so advocates and clients can tell where they are and what
comes next.

- [Assemble Documents workflow](/docs/assemble-documents)
- [Send Client a Questionnaire](/docs/send-questionnaire)

### More control over questionnaire results

Questionnaires can deliver completed documents to the case, send supporting
documents to the advocate, and use selected case information for AI-assisted
follow-up questions.

[Learn more about questionnaires](/docs/send-questionnaire)

### Cleaner optional text in templates

Template authors can use `fix_punctuation` with `ask` and `request` fields to
avoid awkward spacing or punctuation when optional answers are inserted into a
document.

- [Template variables and filters](/docs/template-variables)
- [The `| request` filter](/docs/request-filter)

## Version 1.5.5 — August 22, 2026

### Collect information in fillable PDF templates

Workflow Docs can now use fillable PDF templates that collect information from
clients and other requestees. PDF and DOCX templates can be used together in
the same workflow.

[Learn more about PDF templates](/docs/pdf-templates)

## Version 1.5.4 — August 18, 2026

### Better follow-up on document requests

When a document request is sent, Workflow Docs can record it in LegalServer.
When the request is complete, the advocate can receive an email notification.

[Learn more about requesting client documents](/docs/request-documents)

## Version 1.5.3 — August 6, 2026

### Clearer recovery when a document cannot be uploaded

If a completed document cannot be uploaded to LegalServer, the final screen
explains what happened and provides a download link so the document is not lost.

- [Assemble Documents workflow](/docs/assemble-documents)
- [Request Client Documents](/docs/request-documents)

## Version 1.5.0 — July 22, 2026

### More language and delivery choices

Organizations can offer clients more language options in their workflows, and
signing requests can be sent by SMS when that option is enabled.

- [Advocate Guide](/docs/advocate-guide)
- [Administrator Guide](/docs/admin-guide)

### More flexible document delivery

Advocates can download generated documents when needed, including printable
copies for workflows that do not use electronic signing.

[Learn more about assembling documents](/docs/assemble-documents)

## Version 1.4.5 — July 3, 2026

### Print-ready documents and follow-up actions

Templates can produce print-ready documents, and template authors can set up
useful follow-up actions—such as updating a case or adding a case note—when a
document is completed.

- [Assemble Documents workflow](/docs/assemble-documents)
- [Template Companion Actions](/docs/template-actions)

## Version 1.4.1 — June 27, 2026

### QR codes for helpful resources

Template authors can add a tailored list of community resources, including QR
codes that clients can scan from a printed document.

[Learn more about link enclosures](/docs/link-enclosures)

## Version 1.3.0 — April 23, 2026

### Collect information and signatures from multiple people

A single document workflow can now send each client, witness, or other
requestee a personal link to review documents, provide their information, and
sign. Workflow Docs tracks the requests and assembles the completed documents.

[Learn more about multi-party signing](/docs/multi-party-signature)

## Before Version 1.3.0 — 2025–early 2026

### Client document requests

Advocates can send clients a checklist of needed documents and collect uploads
through a secure link.

[Learn more about requesting client documents](/docs/request-documents)

### AI-assisted questionnaires

Advocates can send a questionnaire to a client, let the client answer in their
own language, and receive a synthesized summary with the completed workflow.

[Learn more about client questionnaires](/docs/send-questionnaire)
